# Use JaaS (Jitsi as a Service) for live video, starting on the free tier

The platform embeds Jitsi in each Class page. We chose JaaS over self-hosting because it needs no servers or DevOps and supports embedding. Self-hosting remains an option if a Community outgrows the free tier or costs justify it.

Public `meet.jit.si` was rejected because embedded use is restricted. Recording is not a Jitsi feature here: the Class coordinator records locally and links the video (see `GLOSSARY.md`, Recording).
